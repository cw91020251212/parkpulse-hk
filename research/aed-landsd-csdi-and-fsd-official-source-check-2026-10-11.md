# 地政總署地圖、CSDI 與消防處 CARE：AED 官方資料應怎樣使用

地政總署的 GeoInfo Map／CSDI 是可信的政府地理資料入口，應納入 AED 查核流程。但查到的資料顯示，**地政總署 CSDI 可見的 AED 資料集有清楚的範圍限制：它是民安隊辦事處及訓練中心的 AED。**[1] 這個圖層可靠，但不是全港所有商場、康文署場地和大學的完整清單。

全港跨類型場地的主要官方來源，應同時採用消防處 CARE 的 AED 資料。消防處在 DATA.GOV.HK 公開的 API 說明，資料涵蓋香港「various premises」，更新頻率標示為 **REAL-TIME**，並提供繁中、英文和簡中版本。[2] 2026-10-11 下載時，繁中及英文檔案各有 **4,676** 筆設備位置紀錄。消防處資料字典定義了場所名稱、地址、裝設詳細位置、座標、是否可供任何人使用、操作及接觸限制、服務時間、品牌和型號等欄位。[3]

## 正確的資料來源分工

| 用途 | 應用來源 | 原因 |
|---|---|---|
| 看地點落在甚麼建築、道路或地段 | 地政總署 GeoInfo Map | 底圖、地址和地理環境由政府地圖提供。 |
| 民安隊辦事處及訓練中心 AED | 地政總署 CSDI AED 資料集 | 這是 CSDI 官方列出的資料範圍，位置來源為民安隊。[1] |
| 商場、體育館、大學、泳池及其他不同場所的 AED 詳情 | 消防處 CARE 即時資料 | 有逐筆名稱、詳細位置、座標、使用限制及服務時間；覆蓋範圍較廣。[2] [3] |
| 場地實際仍否開放、設備是否可取用 | 場地管理方官方頁或直接查詢 | CARE 記錄可列明服務時間，但現場狀態仍應以管理方為準。 |

## 多語言搜尋的實際結果

我同時以繁中、英文和不同名稱查核。GeoInfo Map 的一般地點搜尋 API 是用於地址、建築、地點或設施名稱搜尋；它不是 AED 專用目錄。[4] 用 `AED`、`自動心臟除顫器` 和 `除顫器` 作一般地點搜尋，會混入名稱含 `A`、`自動氣象站` 或其他無關結果。因此，**不要用地圖普通搜尋欄的關鍵字結果當 AED 清單。**

較穩妥的做法是：先取消防處 CARE 的繁中及英文資料，再以名稱、地址和詳細位置交叉合併；最後把官方座標放到地政總署底圖作視覺核對。這樣能利用地政總署地圖的地理準確性，也不會把 CSDI 的民安隊子集誤當成全港清單。

## 直接在消防處官方資料核實到的例子

以下只是證明資料粒度的例子，不是全港完整名單。每一筆都來自消防處 CARE 的繁中或英文官方即時資料。

**大型商場／顧客服務中心**已有清楚位置，例如海趣坊商場在 **1/F 顧客服務中心**；新屯門商場在 **L3 客戶服務中心**；如心廣場一期在 **商場 1/F 禮賓部**；東港城在 **2 樓顧客服務中心**。資料也會分開寫明「可否由任何人使用」及「接觸 AED 是否須職員陪同」，因此不能只看到有 AED 就當作可自由自取。[2] [3]

**體育館**的粒度更細。例如鴨脷洲體育館記為 **3/F 救護室**，服務時間為 **07:00–23:00**；香港公園體育館記為 **G/F 大堂**，服務時間為場地開放時；上環體育館記為 **12/F 主場簽場處旁**；中山紀念公園體育館則分開記錄 **G/F 女洗手間外** 和 **2/F 主場入口**。[2] [3]

**大學校園**亦有直接設備位置。香港大學的官方 CARE 記錄包括明華綜合大樓 **1/F 電梯大堂**、莊月明物理樓 **LG1 男廁對面牆上**、嘉道理生物科學大樓 **平台層回收站旁**、本部大樓 **1/F 大堂 167 室外牆上**及莊月明文娛中心 **2/F 辦事處外**。香港都會大學則有何文田廣場教學中心 **G/F**、葵興校園九龍貿易中心第二座 **11/F、12/F**，以及製衣業訓練中心大樓相關樓層的登記點。[2] [3]

**泳池**方面，CARE 資料確有泳池相關點位，例如香港科技大學室內／室外泳池櫃台的紀錄列出可供任何人使用，服務時間為每天 **07:30–21:30**（場地關閉除外）。但我不會把所有名稱含「泳池」的紀錄直接當成公眾泳池，因為清單同時包含會所、酒店和私人屋苑。康文署公眾泳池仍應以康文署和消防處資料逐點配對，不能用名稱猜測。[2] [3]

## 往後加入 AED 地圖的資料規則

1. **主資料源：消防處 CARE 即時繁中及英文檔。** 每次更新都重新下載、合併、依座標和詳細位置去重。
2. **地圖核對：地政總署 GeoInfo Map。** 用作底圖和座標視覺檢查；若設施在 CSDI 民安隊 AED 圖層出現，可標明其資料提供部門為民安隊。
3. **使用限制必須顯示。** 分開顯示「可否供任何人使用」、「誰可操作」、「誰可接觸」及服務時間；不能把「職員陪同」誤標成可自由取用。
4. **未在 CARE 出現不等於沒有。** 尤其康文署的部分 AED 資訊曾被政府說明為仍在安排上載；沒有逐筆官方記錄時，保留為未核實，不自行補點。[5]
