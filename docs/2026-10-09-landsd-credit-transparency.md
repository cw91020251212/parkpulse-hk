# 地政總署署名牌 75% 透明

## 修正

地圖右下的「地圖資料：地政總署」署名牌，白色背景由近乎不透明的白色改為 `rgb(255 255 255 / 25%)`，即白色底牌 75% 透明。文字、地政總署標誌及官方連結沒有使用整體 `opacity`，因此維持原本可點按和可見性；文字加入淺色陰影，避免在不同底圖上失去辨識度。

## 驗證

390px 寬手機地圖實測：計算樣式為 `rgba(255, 255, 255, 0.25)`、元素自身 `opacity: 1`、連結寬 136px、高 36px 且可見。視覺檢查確認半透明底下仍可辨識文字與綠色地政總署標誌，亦沒有改動地圖控制、marker 或 LandsD 署名連結。

完整驗證亦已通過：`pnpm check`、一般建置、GitHub Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check`。Pages 資料重建期間若外部資料暫時擷取失敗會保留既有已核實快照，最終靜態資料檢查仍確認 183 個營辦商價目快照存在。
