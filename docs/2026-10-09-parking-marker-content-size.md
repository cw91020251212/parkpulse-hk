# 停車場水滴 marker 內容放大

## 修正

停車場水滴 marker 維持 38px 尺寸、白框與尖端座標。中央的空位數、狀態字與符號由 11px 提高到 14px、900 字重，並保持既有深色文字陰影；文字維持單行，使用極小負字距以避免四位數貼邊。

14px 是實測後的最大安全值：15px 的 `9999` 量測寬度為 34.14px，會貼近內框；14px 的 `9999` 為 31.72px，高度 14px，保留安全空間。單字狀態「有／滿／關」均為 13.41px 寬，符號「–」為 7.09px 寬。

## 驗證

390px 手機地圖實測 14 個停車場 marker，實際數值包含 122、308、644 等三位數，均可讀且不改 marker 幾何。`pnpm check`、一般建置、Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check` 全部通過。
