# 路邊位與 Google Maps 評分

日期：2026-10-09

## 官方路邊位

- 新增最後一個互斥的「路邊位」模式，按目前 `📍` 中心 2 公里篩選，不會混入停車場、洗手間、油站或 ATM 結果。
- 咪錶位置和狀態來自運輸署新智能咪錶資料：`V` 有位、`O` 已佔用、`N` 正常、`NU` 暫不可用；只顯示有官方狀態的泊位。
- 同時列出運輸署非咪錶路旁感應試行位，並在 GitHub Pages 清楚標示為建置快照／非即時；智能咪錶則由瀏覽器按 60 秒直接讀取有 CORS 的官方 CSV。
- 同一類型的同一條街會合併為一張卡和一個 marker，顯示總數、有位、已佔用及暫不可用數；距離取該街最近泊位、導航取全街平均座標。合併後仍多於 120 條街才限制顯示最近 120 條，避免密集地區令手機卡死。
- 卡片和地圖提供道路／路段、距離、咪錶收費單位／時段（如有）、來源及駕車導航；到場後可掃實體咪錶動態 QR 使用入錶易，網站不偽造付款 QR。

## Google Maps 用戶評分

- 停車場只在 Google Maps 候選地點距官方座標 **100 米內**，而且有有效分數及評分人數時才顯示星級。
- 評分清楚標為 **Google Maps 用戶評分**；它不影響官方空位、距離或排序，也不是政府或 ParkPulse HK 評分。
- GitHub Pages 使用核實地點快照。這次生成有 **419 個** 嚴格核實的停車場評分；未能嚴格對應或沒有評分的車場不顯示。

`pnpm test:on-street`、`pnpm test:verified-place-links`、`pnpm check`、一般與 GitHub Pages 建置、Pages／PWA 檢查及伺服器語法檢查均已通過。開發端點實測提供 20,849 個有狀態的路邊記錄，其中 145 個為非咪錶感應試行位。
