# 路邊位街道合併與效能保護

日期：2026-10-09

旺角中心的 2 公里範圍實測包含 3,977 個有官方狀態的智能咪錶；其中 769 個顯示有位。逐個建立 React 結果卡和 Leaflet marker 會堵塞手機瀏覽器主執行緒，也不符合「同一條街像一個停車場」的使用方式。

路邊位模式現先按**泊位類型與街道名稱**合併：同一條街只顯示一張卡和一個 marker。卡片與地圖彈窗會顯示該街的總數、有位、已佔用和暫不可用數量；marker 顯示有位數。導航使用該街所有原始泊位的平均座標，距離則使用最近一個泊位；當「只看有位」啟用時，會在完成街道合併後才排除沒有空位的街道，故總數不會被錯誤縮小。

旺角實測由 3,977 個原始泊位合併為 198 條街，其中 138 條有位。因為仍超出手機安全上限，才額外渲染最近 120 條街，並明示完整街道數及可移動 `📍` 縮窄範圍。這個最後保護只套用路邊位，不會改變政府資料、官方更新或其他設施模式。

驗證：街道合併與上限的獨立測試通過；官方咪錶資料解析、TypeScript、一般與 GitHub Pages 建置、Pages／PWA 檢查及 diff 檢查通過。
