# 快速載入與細撳釘修正摘要

## 問題與量度

首次直接讀取政府基本資料實測首字節約 4.2 秒、完整回應約 6.0 秒；即時空位資料完整回應約 4.4 秒。原本頁面把這些遠端資料及環保署充電器資料視為整頁完成的先決條件，啟用「充電設施」篩選時更會暫時遮蔽整個清單，造成明顯的長時間 loading 感覺。

## 修正

網站現在內附 583 筆由官方 API 匯出的停車場基本資料快照 `public/carpark-info.json`。首次開啟會先用這份快照畫出可操作地圖、停車場名稱、距離與清單；即時空位仍會在背景更新，未到前以「更新空位資料」提示，不再用整頁 loading 封鎖操作。

環保署充電器資料改為非阻塞補充：啟用充電篩選而資料尚未回來時，先顯示附近停車場並提示正在補充，資料到達後才套用嚴格的充電器配對篩選。伺服器會在啟動時預熱充電器快取、過期後背景更新，並把來源請求逾時由 120 秒縮短至 25 秒。

長按中心標記由 50px 改為 28px 的青綠小撳釘；在使用者 115% 文字放大下，實際顯示約 32px，針尖仍準確對準手指選點，且地圖不會自動移位。

## 驗證

- 靜態基本資料端點在本機首字節約 2ms；瀏覽器強制重讀 583 筆資料約 22ms。
- 環保署快取端點約 5ms 回應。
- `pnpm test:startup`、空位／充電器／相片檢查、TypeScript、建置、伺服器語法與健康檢查全部通過。
- 長按後撳釘外殼寬度約 32px，針尖與觸控點對準，Leaflet 地圖視野保持不動。
