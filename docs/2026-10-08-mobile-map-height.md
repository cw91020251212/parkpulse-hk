# 行動版地圖延伸摘要

**日期：** 2026-10-08

## 修改內容

一般手機版（非「放大地圖」模式）的地圖高度已由固定 340px 改為根據可視視窗動態延伸。地圖現在會佔用篩選列以下的大部分高度，結果標題與清單會自然排在地圖之後，不再在地圖下方先顯示大塊結果標題區。

高度使用 `100dvh`，並設有 470px 至 680px 的合理範圍，以適應不同手機螢幕，同時保持地政總署標示、Leaflet 控制、marker 和既有地圖專注模式。
