# 篩選列優先次序調整

## 最終排列

篩選控制維持兩行。車高由條件列移到第一行，但依使用習慣排在私家車、電單車、輕型貨車、重型貨車及旅遊巴之後的最尾；它仍屬車輛結構條件，但不佔用首屏常用車種的位置。上行可橫向捲動，向右到底便可完整看到車高選擇。

第二行把路邊位維持在「只看有位」後的第二個控制，後續依次為只看開放、充電設施、無障礙、洗手間、油站及 ATM。車種、車高、路邊位和其餘篩選的狀態、資料模式、觸控尺寸、中英文及鍵盤可達性不變。

## 驗證

- 手機瀏覽器實測確認車高 DOM 位置在最後一個車種後；水平捲到最右時，車高完整位於車種列可見範圍內。
- 繁中下行為「只看有位、路邊位、只看開放、充電設施」；英文對應為 `Available only`、`On-street`、`Open only`、`EV charging`。
- `pnpm check`、`pnpm build`、`pnpm build:pages`、`pnpm test:pages`、`pnpm test:pwa` 及 `git diff --check` 通過。
