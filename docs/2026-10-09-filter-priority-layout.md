# 篩選列優先次序調整

## 調整

篩選控制維持兩行。車高由條件列移到第一行，並放在車種列最前，因此手機首屏直接可見；私家車、電單車、輕型貨車、重型貨車及旅遊巴仍保留在同一個可橫向捲動的車輛列。第二行把路邊位移至「只看有位」後的第二個控制，後續依次為只看開放、充電設施、無障礙、洗手間、油站及 ATM。

只改排列及一個車種分組的 flex 間距。車種、車高、路邊位和其餘篩選的狀態、資料模式、觸控尺寸、中英文及鍵盤可達性不變。

## 驗證

- 390px 手機截圖確認首屏次序為「車高、私家車、電單車、輕型貨車」，下行為「只看有位、路邊位、只看開放、充電設施」。
- DOM 實測繁中與英文都確認車高位於私家車前；英文下行為 `Available only`、`On-street`、`Open only`、`EV charging`。
