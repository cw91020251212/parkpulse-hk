# 詳情浮層層級與返回操作修正

## 修正內容

停車場詳情面板的層級已提高至 `z-index: 1100`。這高於地圖展開按鈕（`1002`）、地政總署版權／標誌（`1001`）以及 Leaflet marker，因此開啟詳情時不會再被這些地圖元素遮住。

每次由 marker 或清單卡片開啟詳情時，App 會在同一網址加入一筆專用歷史狀態。手機或瀏覽器的返回操作會優先關閉詳情並保留在「泊邊有位」；詳情右上 X 亦會回退該專用狀態，避免下一次返回直接離開網站。

## 驗證

瀏覽器實測詳情層級為 `1100`，高於展開按鈕 `1002` 和官方署名 `1001`。使用 `history.back()` 後詳情已關閉且網站仍在同一頁；使用 X 關閉後專用歷史狀態亦已清除。TypeScript、建置、空位、充電、相片及快速啟動檢查均通過。
