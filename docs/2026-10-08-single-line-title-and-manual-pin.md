# 單行主標與手指選點修正摘要

## 修正內容

品牌主標「泊邊有位」調整為桌面 26px、手機 24px，並加入 `white-space: nowrap`，在 100%、115% 和 130% 文字放大設定下都維持單行；不再以過大的字級擠壓頂部控制。

大型青綠搜尋中心定位針不再顯示在初始香港中心、搜尋地區或「使用我的位置」的結果。它只會在使用者長按地圖選取位置後出現，並連同 2 公里範圍圈顯示。長按選點不再觸發 Leaflet `setView`，因此地圖保留使用者當前視野，針留在手指選取處。

因應文字／介面放大使用 CSS `zoom`，長按座標由螢幕像素轉換為 Leaflet 內部座標時會按地圖可視尺寸比例校正，避免定位針隨放大倍率偏移。
