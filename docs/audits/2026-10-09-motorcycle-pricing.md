# ParkPulse HK PWA：電單車收費顯示範圍稽核

- **稽核日期：** 2026-10-09
- **範圍：** 選擇電單車（`motorCycle`）時，卡片及詳情是否可能展示私家車收費、官方收費備註或營辦商價目；提出避免誤導的最小修正。
- **方式：** 只讀檢查指定程式檔與資料，並核對官方公開來源；本次沒有修改任何產品程式或既有文件（只新增本稽核紀錄）。

## 結論摘要

**存在車種錯配風險。** 直接按車種索引的時租結構收費及營辦商價目有車種隔離；但官方備註抽取器 `getOfficialPricingNotes` 沒有車種判斷。卡片和詳情在電單車選擇狀態下也會顯示這些備註。因此備註若是私家車價目，可能以「官方收費參考／官方收費備註」的名義出現在電單車結果。現有 `operator-rates.json` 的 183 條營辦商紀錄全都只有 `privateCar`，故目前資料不會直接命中電單車營辦商價目，但應避免未來增加車種欄位前沿用私家車資料。

## 現況（按程式檔）

### 收費取得與備註抽取：`src/domain/carpark.ts`

- `getVerifiedOperatorRate(info, vehicleType)` 以 `info.operatorRates?.[vehicleType]` 取值（第 27–29 行）；這個取值本身是車種專屬的。
- `getOfficialHourlyCharges(info, vehicleType)` 先取 `info[vehicleType]?.hourlyCharges`（第 189–193 行），只有在該車種沒有結構化價格時才解析備註。`extractHourlyChargesFromNotes` 依 `VEHICLE_NOTE_PATTERNS` 跟蹤備註中的車種語境，只會回傳匹配目前車種的時租（第 141–168 行）。因此這一條時租解析路徑有車種篩選。
- **缺口在一般官方備註：** `getOfficialPricingNotes(info)`（第 170–187 行）僅把包含金額的備註行及前置收費語境拼接，沒有接收 `vehicleType` 參數，也沒有依電單車／私家車語境篩選。
- `formatPrice` 以目前車種的官方時租首項格式化（第 204–207 行）。

### 卡片：`src/components/ParkCard.tsx`

- 第 21–24 行先取目前車種營辦商價目，若無則取目前車種官方時租；若沒有時租，無條件以 `getOfficialPricingNotes(info)[0]` 作 `pricingReference`。
- 第 34–35 行卡片會顯示 `cardPricing`，或顯示「官方收費未提供」。若電單車沒有專屬時租、而資料備註含私家車收費，卡片可能顯示該私家車備註為官方參考價。
- 第 33 行空位標籤部分按所選 `vehicleType`，但空位車種呈現不是本次價格稽核重點。

### 詳情：`src/components/ParkDetail.tsx`

- 第 22–25 行營辦商價目及時租表依目前車種索引；但 `pricingNotes` 無營辦商價目時直接取 `getOfficialPricingNotes(info)`，沒有車種過濾。
- 第 36–37 行詳情價錢欄及官方時租區會顯示價格／備註。故電單車詳情同樣有展示不屬電單車的官方備註的風險。
- 詳情來源連結指向官方政府資料集，並不能單獨證明頁面中每則備註適用於當前選擇車種。

### 營辦商資料：`public/operator-rates.json`

- JSON 自述 `attempted: 183`、`records` 有 183 條；只讀統計結果：**183 條紀錄均僅有 `privateCar`，`motorCycle` 紀錄為 0**。
- 例：ID `30`、`31`、`32` 的德福價目只有 `privateCar`；其他列出的領展紀錄亦以 `privateCar` 為鍵。
- 由於查詢以 `motorCycle` 為鍵，現有這批營辦商價目不會直接作為電單車營辦商價目輸出；但不能據此推論其停車場沒有電單車費率或電單車不能泊車。

## 電單車使用者影響

電單車使用者可能把私家車收費理解為電單車收費，造成到場預算錯誤，尤其是卡片層級的「官方收費參考」會將備註放在價錢附近。詳情區也以官方收費備註呈現，若備註車種是私家車，使用者可能誤認為該價格適用於電單車。除此之外，現有營辦商價目只有私家車紀錄，電單車目前容易看到「未提供」而非其可能存在的實際場內價格；此處應表達為「本站未有核實電單車價目」，不能解讀成免費或與私家車同價。

## 證據與官方資料

1. **程式碼路徑**（本地提供檔案，非外部事實）：
   - `carpark.ts` 第 170–187 行的官方備註抽取沒有車種參數；第 141–168 行的備註時租解析則有車種語境判斷。
   - `ParkCard.tsx` 第 21–24、34–35 行；`ParkDetail.tsx` 第 22–25、36–37 行，證明兩處把一般備註用於所選車種介面。
   - `operator-rates.json` 全 183 條僅 `privateCar`，沒有 `motorCycle` 鍵。
2. **運輸署營運政府停車場官方頁**：頁面分別列有「私家車／客貨車每小時收費」及「電單車日間收費（08:00–23:00）、電單車晚間收費（23:00–08:00）」等獨立欄位，並註明新收費由 2026-03-01 生效。這確認官方資料中確有按車種區分的收費欄位，不能以私家車價格替代電單車價格。該頁列出的電單車計費時段也與私家車每小時收費的時段不同。
   - URL：<https://www.td.gov.hk/tc/transport_in_hong_kong/parking/carparks/gov_car_parks_managed_by_td/index.html>
3. **data.gov.hk「空置車位資訊（整合版）」官方資料集**：官方說明其整合運輸署及起動九龍東辦事處提供的空置車位數目及基本停車場資訊。這個資料集描述的是空位及基本停車場資訊來源；不能只憑資料集名稱或頁面來源連結，認定每則備註均是目前選定車種的適用價目。
   - URL：<https://data.gov.hk/tc-data/dataset/hk-dpo-datagovhk1-carpark-info-vacancy>
4. **營辦商價格來源示例（資料檔所列官方連結）**：例如德福廣場官方泊車頁及領展官方停車場頁是 `operator-rates.json` 中記錄的來源，但現有 JSON 僅將相關價目編在 `privateCar` 下；來源本身不構成電單車費率證據。
   - <https://www.telford-plaza.com/tch/parking>
   - <https://www.linkhk.com/tc/parking/1004>

## 最小修正建議（不代表本次已實作）

1. **阻止跨車種備註冒充價格：** 將官方備註選取改為接收 `vehicleType`，只呈現可明確判斷適用於所選車種的備註；不明確或沒有車種標示的收費行，不能當作該車種價格展示。若短期無法可靠解析備註，最安全的小改動是電單車視圖不展示未分車種的價格備註。
2. **明確區分「未提供」與零收費：** 電單車沒有已核實的專屬價目時，顯示「本站未有核實電單車收費；請以場內標示／營辦商公布為準」，不要回退使用私家車價錢，也不要暗示免費。
3. **營辦商價目維持車種鍵控：** 只有官方來源明確刊載電單車收費並記錄適用車種後，才新增 `motorCycle` 價目。沒有車種證據時保持無價，避免複用 `privateCar`。
4. **涵蓋卡片與詳情兩處：** 修正共用備註邏輯並確認 `ParkCard` 與 `ParkDetail` 均套用相同車種規則；保留清楚可辨認為電單車的官方備註及相應來源。

## 未能由公開資料確認的限制

- 運輸署頁面是**運輸署營運的政府停車場**資料，不能推及所有私營停車場、所有 operator-rates 紀錄，或 ParkPulse 全部停車場。
- 本次未對 183 個營辦商來源逐一重查／驗證每個停車場的電單車費率；`operator-rates.json` 的 `privateCar` 鍵只證明本站該檔紀錄分類，不能證明營辦商沒有電單車價目。
- 本次提供的指定程式檔中未見各停車場實際官方備註樣本與完整輸入資料，故確認的是**無車種過濾的顯示路徑及風險**，不是已證明每個電單車頁面當下必定顯示一筆私家車金額。
- 官方收費可能依時段、日泊／夜泊、泊車資格或現場告示等條件改變；上述政府頁的電單車日間／晚間價目不能直接套用到其他營辦商或一般時租。
- 網頁及價目會更新；稽核只按 2026-10-09 可讀內容及本次提供檔案記錄，不保證日後價格仍相同。
