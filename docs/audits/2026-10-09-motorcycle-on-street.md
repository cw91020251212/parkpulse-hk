# ParkPulse HK PWA：電單車路邊泊位支援範圍審核

**審核日期：** 2026-10-09
**範圍：** 咪錶、非咪錶感應試行泊位、運輸署官方路邊電單車泊位分佈／導向。
**方式：** 唯讀檢視指定程式與快照；讀取運輸署官方資料字典及官方網頁。未修改產品程式或既有文件。

## 摘要結論

現行路邊顯示資料源包括運輸署新智能咪錶及非咪錶路旁泊車感應試行。兩者官方 `VehicleType` 字典均明確排除電單車於一般車種 `A`；另有 `C`（旅遊巴／旅遊車）、`D`（傷健人士）及咪錶 `G`（貨車），沒有任何電單車代碼。故不可將任一一般 `A` 位或其他不匹配車種的位標示為電單車可用，也不可把其「空置」狀態解讀為電單車可泊。

運輸署另有獨立的「路邊電單車泊車位分佈」官方導向頁，指示使用香港出行易網頁／流動應用程式搜尋。現有公開資料不能支持將電單車位併入本 PWA 現有咪錶／感應即時空位層；可行最小做法是電單車選取該層時停止展示不適用一般位，清楚說明來源範圍，並提供運輸署所指官方入口。

## 現況（程式與快照）

- `lib/on-street-parking.mjs`：第 1–4 行定義兩個資料源：咪錶位置／狀態 CSV，及非咪錶試行位置／狀態 API。第 55 行把來源 `VehicleType` 原樣保留，沒有依車種判斷可否展示。`recordFor` 僅要求座標、狀態與 ID 存在，不校驗車種；咪錶與試行位均可進入輸出。
- `src/App.tsx`：第 99 行僅在開啟路邊模式時載入資料；第 113–115 行只按距離、可用篩選及分組處理路邊結果，沒有把目前 `vehicleType` 用於路邊候選篩選。第 154 行有可選車種控制，但其選擇不約束路邊結果。
- 指定快照 `public/pages-data/on-street-parking.json`：`generatedAt` 為 `2026-10-08T20:31:50.819Z`；只有 `nonMetered`，共 145 筆：`A` 122 筆、`D` 20 筆、`C` 3 筆。狀態為空置 52、佔用 15、不可用 78。快照本身沒有咪錶資料；不能由此推斷線上咪錶資料不存在。
- 因為一般 `A` 的字典定義明確排除電單車，介面在選取電單車時仍展示這些路邊試行位（也可能展示 `C/D` 或未來咪錶位），構成車種適用性誤導。即使某筆顯示「空置」，也不表示對電單車合法／適用。

## 電單車影響

1. 電單車駕駛者可被誤導到未指定予電單車的咪錶或感應試行位，並可能把空置狀態誤認為可停泊。
2. 選擇車種和路邊泊位的語義不一致，缺乏適用資料時沒有解釋或可信官方替代入口。
3. 程式保留 `VehicleType` 卻未用於資格判定，未來若來源加入新代碼，亦有未經核實便顯示的風險。

## 證據與官方核實

### 1. 咪錶泊位

運輸署《咪錶泊車位資料規格》欄位 `VehicleType` 接受值為 `A, C, G`：`C` Coaches、`G` Goods Vehicles；`A` 是 Any Vehicles，但明確排除中型／重型貨車、巴士、電單車及單車。因此此資料集不提供可識別為電單車的咪錶位；不能把 `A` 認作包括電單車的「任何車輛」。

官方資料字典 PDF：<https://www.td.gov.hk/datagovhk_td/metered-parking-spaces-data/resources/tc/dataspec/metered_parking_spaces_data_dataspec.pdf>
程式指定咪錶 CSV URL：<https://resource.data.one.gov.hk/td/psiparkingspaces/spaceinfo/parkingspaces.csv>

### 2. 非咪錶感應試行位

運輸署非咪錶路旁泊位資料規格列 `VehicleType` 可接受值 `A, C, D`：`A` 是排除中型及重型貨車、巴士、電單車及單車的任何車輛；`C` 是 Coach；`D` 是 Disabled。當前快照中只見 `A/C/D`，沒有電單車專用代碼。因此這些試行位均不能作為電單車泊位呈現；`D` 的傷健人士用途亦不能由電單車選項推定適用。

官方資料字典：<https://data.nmospiot.gov.hk/api/pvds/Download/nonmeterparkingspacedataspec>
程式指定位置 API：<https://data.nmospiot.gov.hk/api/pvds/Download/parkingspace>
程式指定狀態 API：<https://data.nmospiot.gov.hk/api/pvds/Download/occupancystatus>

### 3. 電單車路邊泊位官方導向

運輸署官方「路邊電單車泊車位分佈」頁面表示，為方便電單車駕駛者預先計劃行程，路邊電單車泊位分佈可透過運輸署「香港出行易」網頁及流動應用程式搜尋，並提供「此連結」。這證明運輸署有獨立的電單車路邊泊位分佈概念／官方查詢導向；該頁未提供可直接替代本程式即時佔用資料的欄位或 API 說明。

官方導向頁：<https://www.td.gov.hk/tc/transport_in_hong_kong/parking/on_street_motorcycle_parking_spaces/index.html>

## 最小修正建議（尚未實作）

1. 在路邊資料呈現邊界依目前所選車種篩選；電單車選取時，對現有咪錶／非咪錶即時來源不輸出任何泊位結果。判定採保守白名單：只有有官方字典明確證明適用的代碼才可展示；未知代碼不可當作電單車相容。
2. 電單車模式提供專屬空狀態說明，指出本資料源只涵蓋運輸署咪錶及非咪錶感應試行位、兩字典均不含電單車適用項，避免只呈現普通「沒有結果」或把一般位留在地圖上。
3. 加入運輸署官方「路邊電單車泊車位分佈」頁的連結，依官方指向使用香港出行易查詢；不要把此導向描述成即時空位或保證空位。
4. 對其他車種亦應按正式代碼白名單核對，尤其不要把 `C/D/G` 一概當成一般車位；本審核重點僅電單車，未提出未經核實的完整車種映射。

## 公開資料無法確認的限制

- 本審核查到的運輸署官方導向頁稱可在香港出行易查詢，但頁面內容沒有披露底層資料下載 API、格式、授權／可再用條件、更新頻率或即時佔用狀態；故不能確認有可直接整合入 PWA 的官方電單車即時 feed。
- 公開字典核實的是來源指定車種及代碼，不代表每一個具體路段的現場標誌、臨時交通安排或某車輛的實際停泊合法性；應以現場交通標誌及正式規則為準。
- 指定快照只包含 145 筆非咪錶資料且全為 `A/C/D`。它不是完整即時來源，也不證明運輸署在香港出行易中的電單車位數目或當前可泊數。
- 本審核沒有驗證香港出行易連結目的地可用性、完整地理覆蓋或資料更新時間；報告只記錄運輸署頁面明示的導向。
