# 充電設施：交叉核對及篩選修正

本次把「充電設施」篩選從只讀取運輸署停車場基本資料的 `facilities` 欄，改為同時接受已通過環保署官方充電器名稱、地址及座標保守配對的結果。這修正了荃灣停車場（`tdcp3`）的遺漏：官方充電器資料在核對時提供 162 個中速充電器和 34 個可用，而停車場的基本資料欄並沒有標示 `evCharger`。

外部資料只用於覆蓋核對。EV-Boy 的荃灣清單同樣列出荃灣停車場為 Cornerstone、162 個 Type 2 中慢速充電位；Kilowatt 列 157 個 AC 位，顯示第三方網站的更新時點和統計口徑可不同。兩者均列出如愉景新城、Plaza 88、如心廣場、石圍角及海盛路等其他荃灣站點。官方環保署 GB/T 地圖頁於 2026-09-09 更新，則提供公共 GB/T 設施清單。

因此，網站不會把第三方的私人、月租、13A、快將啟用或未核實站點直接混入「有充電設施」停車場結果。未來如要顯示不在即時停車空位資料內的公眾充電站，應以獨立「官方充電站」模式標示其沒有車場即時空位，而不是混為一談。

`pnpm test:charging` 現已直接驗證荃灣停車場即使 `facilities` 沒有 `evCharger`，在有官方配對時仍通過充電篩選；型別、一般與 GitHub Pages 建置、Pages／PWA 檢查和 diff 檢查均通過。
