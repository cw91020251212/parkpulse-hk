# 紅釘名稱及地址

紅釘輕點會下載本站公開的地政總署 iG1000 命名場地索引，使用原有 Polygon/MultiPolygon 邊界在手機本機識別。地名和地址置頂；有多個含點範圍時先顯示較具體的小範圍。無含點範圍時，只列距實際場界不超過 100 米的「附近」資料並顯示距離。沒有資料才顯示未記錄及可收起坐標。

本版本包含完整site及subsite名稱表所提供的有名範圍，以及其官方街道地址；沒有下載獨立building全表，不把此功能稱作所有點均有門牌。sourceCounts保留四張原始表的完整筆數及來源版本；鏡像取得時間和官方記錄更新日期分開保存。

名稱並非按附近洗手間、飲水機點半徑推測；建築物孔洞不會當成樓宇內。GPS／手動坐標不上傳，不新增代理、資料庫或 Manus 託管。原紅釘、長按、3D目標和共享Popup關閉行為不改。

正式來源：

- [地政總署地理參考數據庫](https://www.landsd.gov.hk/en/survey-mapping/mapping/other-products/geo-reference-database.html)
- [DATA.GOV.HK iG1000](https://data.gov.hk/en-data/dataset/hk-landsd-openmap-development-hkms-digital-g1k)
- [CSDI iG1000](https://portal.csdi.gov.hk/csdi-webpage/dataset/landsd_rcd_1637226341468_86480)
- [CSDI 開放資料使用條款](https://portal.csdi.gov.hk/csdi-webpage/doc/TNC?lang=en)

地政總署、政府及 CSDI 保留資料的知識產權。本網站在資訊小窗提供來源連結，下載快照保留資料版本。網站 GeoInfo Map 的專用 identify 與正式開放資料是不同接入途徑：本實作使用開放資料，不複製網站key或偽造Origin。
