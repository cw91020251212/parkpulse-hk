# 官方基本資料停車場來源核對

日期：2026-10-09

目前應用的運輸署空置車位資料只涵蓋與運輸署合作提供資料的停車場，並非全港公眾停車場普查。資料本身可合法重用，但不應把沒有空位欄位的紀錄寫成零空位。

本輪核對主要營辦商及政府資料後，政府產業署「產業署轄下供公眾使用的政府停車場」是唯一已確認同時符合以下條件的補充來源：官方、可取得全量機器可讀目錄／API、可按 DATA.GOV.HK 條款重用、並明確屬於沒有即時空位承諾的基本資料。它會是「包括無即時數據」首批補充。

領展、威信、信和、港鐵、房委會／房協和一般商場個別官方頁可作人工核實或導流，但現階段均沒有已確認可重用的全量公開目錄／API。領展條款要求留意使用、複製、分發或發布網站材料的限制，因此不會批量鏡像其資料，也不會宣稱全港已完整收錄；有明確授權或官方開放資料後才擴展。

富善和明雅仍是兩個獨立車場。明雅的領展單場公開端點按用戶點名加入、保留來源連結並標為建置快照；它是具體個案，不會被當作領展的全量目錄或擴展成批量鏡像。

## 採用與不採用來源

| 來源 | 是否採用 | 原因 |
| --- | --- | --- |
| 運輸署空置車位資訊 | 採用 | 現有即時基準；官方 JSON/API 與可重用條款。 |
| 政府產業署供公眾使用政府停車場 | 採用 | 官方全量機器可讀資源；基本資料，不宣稱即時空位。 |
| 領展、威信、信和、港鐵、房委會／房協、商場官方頁 | 暫不批量採用 | 缺少可確認的全量可重用目錄／API，或條款未授權批量重用。 |

## 實際資料確認

產業署英文 JSON 資源為 `https://www.gpa.gov.hk/doc/psi/ds/psi-t-cp_ENG.json`。2026-10-09 下載時有 19 筆記錄，欄位包括車場名稱、地區、地址、車種、車位數、限高、開放時間、充電器、傷健車位、收費、電話及網站。檔案含 UTF-8 BOM 與字串內未轉義的換行，建置器必須先安全清理控制字元才可解析，不能直接 `JSON.parse`。

其 JSON 沒有地圖所需 WGS84 座標。地政總署位置搜尋 API `https://www.map.gov.hk/gs/api/v1.0.0/locationSearch?q=<車場名稱或地址>` 會回傳 HK1980 Grid 的 `x`／`y` 和中英文名稱；坐標轉換 API 說明為 `http://www.geodetic.gov.hk/transform/v2/`，對 HK1980 Grid 輸入使用 `inSys=hkgrid`、`n=<northing>`、`e=<easting>`，並設定 `outSys=wgsgeog` 取得 WGS84。這兩個服務均為地政總署公開服務，產生的座標在快照記錄內須保留其來源。

同日查詢運輸署 API 得 `info` 584 筆、`vacancy` 584 筆，因此沒有「有運輸署基本資料但完全沒有 vacancy 記錄」的停車場。當中有 12 筆沒有 `privateCar` 空位條目，主要是的士、貨車或特定車種車場；它們不是私家車「無即時數據」的補充主體。故首批私家車補充應來自產業署 19 筆目錄，並按名稱、地址及坐標消歧後排除已由運輸署覆蓋的重複車場。

## 主要來源核對摘要

領展、威信、信和、港鐵、房委會／房協與一般商場均找到官方頁或應用程式功能描述，但未找到可合法批量重用的完整公開目錄／API。領展官方條款載明網站資訊與材料未經事先書面許可不得使用、複製、散佈或發布，故不得把其網站當成全量資料庫。威信官方只披露管理規模；信和只披露 120+ 停車場與其應用程式功能；港鐵官方可核實七個車站停車場但未公開 API；房協稱管理 58 個停車場但沒有可確認重用的全量機器可讀目錄。它們只可在取得書面重用權或新的官方開放資料後擴展。

## 實作結果（2026-10-09）

本次把上述兩類資料合併為 `official-static-carparks.json`：產業署 19 筆官方基本資料，以及用戶點名、具獨立官方 ID 的領展明雅停車場（`4324`）。明雅以公開官方端點的即時回應建立**可追溯建置快照**，包括地址「新界大埔安埔里 7–11 號明雅苑停車場」、WGS84 座標、電話、私家車總位 319、官方價目及當次公布空位。它在介面固定標示為「領展官方空位快照」，絕不稱作運輸署即時空位；快照時間沿用既有 5 分鐘資料延遲提示。該端點並沒有公開限高或開放時間，所以應用如實顯示「未提供」，不從現場或其他來源猜測 2 米。

產業署 19 筆紀錄中有 17 筆其實已被運輸署車場目錄覆蓋；它們不會產生第二張卡。前端以去除「停車場」及營辦商括號的正規化名稱，加上約 200 米座標限制，將官方基本資料併回既有的運輸署卡；已有空位回應一律維持運輸署即時狀態。只有沒有同址運輸署記錄的產業署車場才會新增為「未提供即時空位」。這避免同一座北角政府合署之類的車場重複顯示。

「包括無即時數據」仍然是用家選擇：預設只保留現有即時結果；點按後自動解除「只看有位」，才加入沒有即時空位的官方基本資料卡及 marker。明雅作為領展快照，會保留其公布空位、總位、價目及來源標籤。所有資料仍限定在目前 2 公里、目前車種與原有地圖範圍內。
