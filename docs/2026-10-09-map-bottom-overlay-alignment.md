# 地圖底部左右浮動牌對齊與半透明化

## 最終排版

一般地圖模式下，左側「查看 N 個停車場／油站／ATM」與右側「地圖資料：地政總署」共用 `bottom: 22px`，兩者底線對齊，並與 Leaflet／LandsD 最底版權文字頂部保留約 5px 小間隙。地圖專注模式仍使用既有右上署名位置。

左右兩個底牌均使用 `rgba(255, 255, 255, 0.5)` 半透明白底；左牌文字與下箭頭採深黑藍 `#182d35`，右牌保留地政總署文字與官方標誌。左牌不再有 hover／觸控後的 70% 白底或背景模糊，因此不會比右牌看起來更白。所有文字、標誌、按鈕及連結維持 `opacity: 1`，透明度只應用在底牌背景。

## 驗證

手機地圖實測：左右牌背景均為 `rgba(255, 255, 255, 0.5)`、均沒有背景圖片或模糊效果；把指標移到左牌後樣式不變。兩牌底線維持對齊，Leaflet／LandsD 版權文字完整存在且沒有被覆蓋。`pnpm check`、一般建置、Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check` 全部通過。
