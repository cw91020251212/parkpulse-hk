# 地圖底部左右浮動牌對齊與半透明化

## 修正

一般地圖模式下，左側「查看 N 個停車場」與右側「地圖資料：地政總署」現在共用 `bottom: 30px`，兩者底線對齊。這個位置在 Leaflet 最底版權列上方保留空間；地圖專注模式仍使用既有右上署名位置。

兩個底牌只調整背景透明度：左側深藍底為 `rgba(9, 36, 58, 0.5)`，右側白底為 `rgba(255, 255, 255, 0.5)`；文字、地政總署標誌、官方連結和按鈕本身維持 `opacity: 1`。

## 驗證

390px 手機地圖實測：左右牌底線同為 559px，Leaflet／LandsD 版權列由 572.2px 至 589px，兩者無重疊且版權文字完整存在。地圖專注模式的署名仍位於 `top: 58px`，結果按鈕隱藏。`pnpm check`、一般建置、Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check` 全部通過。
