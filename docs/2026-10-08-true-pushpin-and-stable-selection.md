# 真撳釘與穩定長按選點修正

## 問題

長按選點原先使用的是小水滴 marker，外觀容易和停車場的空位水滴混淆；手指在完成長按後的微小移動，亦仍可能由 Leaflet 拖曳令地圖與選點移位。

## 修正

- 搜尋中心改為獨立 SVG 小撳釘：青綠色圓釘頭、橫托及白色針腳，與停車場水滴 marker 不同。
- SVG 的針腳底端為 Leaflet 座標錨點，選點後尖端會對準使用者手指按住的位置。
- 長按開始時記錄地圖中心與縮放；確認選點時停止 Leaflet 動畫、還原開始時視野，並暫時停用拖曳至手指放開。
- 地圖全域關閉拖曳慣性，避免放開手指後的延遲滑動。

## 驗證

以原生 `TouchEvent` 模擬 0.76 秒長按、再加入 6×4px 的手指微移後：SVG 撳釘已出現、地圖 pane 維持不動，且 marker 外殼底端與按點的水平／垂直偏差均少於 2px。TypeScript、建置、空位、充電、相片及快速啟動檢查均已通過。
