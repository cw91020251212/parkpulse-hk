# 公廁手動位置維護

`src/data/manual-toilet-positions.json` 是所有用家共同讀取的唯讀設定。只有專案管理者把用家確認的近似位置加入這個檔案並部署後，大家才會看到共用位置。

```json
{
  "version": 1,
  "positions": [
    { "toiletId": "資料中的公廁 ID", "latitude": 22.3, "longitude": 114.1 }
  ]
}
```

- 只可調整場地級或位置未核實的公廁；官方精確點不能拖動，官方來源座標不會被覆寫。
- 不設可見的「開始編輯」按鈕。按住灰色場地標記約 1.3 秒才會解鎖拖動；一般點擊不會移動標記。
- 每次拖放後才出現「繼續調整」和「確定儲存」；繼續會再次允許拖動，確定才會把最終位置寫入這個瀏覽器的 `localStorage`。
- 本機位置只影響同一瀏覽器。它不會改變官方座標，也不會自動上傳或改動其他用家的資料。
- 如要把本機設定交給專案管理者，於 App 網址後加上 `?exportManualToiletPositions=1`，網頁會下載 `parkpulse-manual-toilet-positions.json`。把這個檔案交給管理者，確認後才會合併至共用設定。
- 解析器只接受香港範圍內的有限數值座標；無效記錄會忽略。共享設定由 GitHub 專案檔與部署管理，不把管理密碼放進公開程式碼。
