# 卡片與浮層可讀性審查（2026-11-03）

## 已重現的根因

使用者截圖是洗手間全畫面清單，部分卡片只顯示備註的中間段，標題和圖示消失。以正式資料及大埔測試座標 22.4515 / 114.1702 重現：51 張卡有 33 張的標題頂部位於其卡片邊框上方。例子「東昌街體育館」卡片外框只有 152px、主內容約 314px，標題偏移 -67px；「東昌街社區會堂」主內容約 402px，標題偏移 -111px。

原因不是資料缺失，而是受限高度的 `.results-list` 採隱含 `auto` Grid 軌道，配合卡片 `overflow:hidden` 令軌道可縮至最小高度；外卡片又垂直置中，把過高內容的前後剪掉。148/152px 是既有最小高度，不是程式明確寫死的 height，但在此軌道計算中實際成為受壓縮列高。只加 `flex-shrink:0` 不能解決 Grid item 的問題。

共用修正為 `grid-auto-rows:max-content`，保留由整個結果清單捲動，不另加卡片內捲軸。操作欄改由卡頂開始，不再跟長備註平均拉成巨大按鈕。修正後相同 51 張卡標題被自己邊框剪走的數目為 0，長卡可按內容增高，全部資料保留。
