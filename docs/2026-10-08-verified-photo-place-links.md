# GitHub Pages 已核實相片地點修正

日期：2026-10-08

## 問題

GitHub Pages 是純靜態網站，無法安全呼叫需要私密憑證的 Google Maps 相片代理。先前「地圖相片」連結只用名稱及地址搜尋，可能只開到地址結果，未必會進入有相片的正確地點。

## 修正

- 新增 `public/pages-data/verified-place-links.json`：由既有受管相片代理建立的 Google Maps `query_place_id` 快照。
- 全港掃描 1,620 個停車場、食環署公廁及康文署場館，取得 1,314 個同時有相片、候選地點與官方座標相距不多於 100 米的精確連結：493 個停車場、711 個食環署公廁、110 個康文署場館。
- 食環署公廁額外要求 Google Maps 地點名稱含公廁／浴室語義；因此不會把奶路臣街公廁錯連到 60 米外的酒店。
- 靜態卡片只在精確快照存在時才顯示「已核實相片 ↗」；沒有合格快照時顯示「暫無已核實相片」，不再使用誤導性的泛用搜尋連結。
- 動態伺服器版也使用公廁名稱語義及 100 米上限，保留既有的內嵌相片、歸屬和距離。
- 同時把停車場篩選「開放中」改成「只看開放」，其 ARIA 說明明確指出這不代表有空位。
- 修正金管局 ATM API 偶爾只回傳 100 筆時不會使用不完整主來源，會自動改用 1,959 筆的金管局 ArcGIS 後備資料。

## 驗證

- `pnpm test:verified-place-links` 驗證 1,314 個精確 `query_place_id`、100 米內距離及公廁語義。
- `pnpm test:toilet-photos` 驗證動態公廁相片仍是 100 米內且地點本身為公廁／浴室。
- 靜態瀏覽器測試：洗手間模式顯示 31 個結果；花園街體育館、奶路臣街公廁及旺角道公廁均使用精確 Place ID URL，沒有泛用地址搜尋連結。
- TypeScript、一般／GitHub Pages 建置、PWA、資料端點、現有停車／相片／洗手間／ATM 檢查均通過。
