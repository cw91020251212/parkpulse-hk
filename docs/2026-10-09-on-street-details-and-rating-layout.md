# 路邊位詳情與評分首行修正

## 路邊位卡片

- 街道卡面改為兩條完整摘要：`有位 X／共 Y` 與 `已佔用 X · 暫不可用 Y`；不再把核心數字或付款提示截成省略號。
- 卡片主體可點按並開啟固定詳情面板；導航保留為獨立小按鈕。
- 詳情列出合併街道所有有官方狀態泊位的總數、有位、已佔用、暫不可用、涵蓋路段、統計範圍、時段／收費（若官方資料提供）、付款提示、來源及導航。
- 總數清楚限定為「運輸署官方狀態資料中的咪錶／感應試行位」；沒有即時狀態的普通泊位不會被假稱包含。
- 結果標題在手機改為單行可讀，來源另起一行，避免「最近 120 條街／共 N 條街」被壓成直排。

## Google Maps 評分

- 已核實評分移到停車場名稱的同一行、名稱右側；長名稱會保留評分及距離所需空間。
- 評分是獨立外部 Google Maps 連結，不再置於可點按停車場卡片 button 裏，因此沒有巢狀互動元素。

## 驗證

- 瀏覽器驗證：花園街卡顯示 `有位 9／共 34`、`已佔用 25 · 暫不可用 0`，付款提示不在卡面，點按後詳情包含統計範圍與涵蓋路段。
- 瀏覽器量測：評分與停車場名稱同一行，兩者頂部皆為 306px；評分連結不在 button 內。
- `pnpm test:on-street`、`pnpm test:on-street-limit`、`pnpm check`、一般與 GitHub Pages 建置、Pages／PWA 檢查、`node --check server.mjs` 和 `git diff --check` 通過。
