# 地圖版面與地區搜尋修正摘要

## 修正內容

- 移除地圖左下角的深色「有位／已滿／未知」圖例；停車場 marker 本身已用顏色、數字或狀態文字表達同一資訊。
- 一般手機版地圖改為依可視高度及使用者文字放大比例計算高度，保留地圖底部圓角與下方結果入口，不再讓地圖實際結尾落在螢幕外。
- 在地圖左下方加入「查看 N 個停車場」按鈕；點擊後平滑捲動至完整結果清單，避免手指在 Leaflet 地圖上滑動時只平移地圖而無法到清單。
- 在地圖內加入「搜尋地區」按鈕和文字輸入面板，支援香港 18 區的中英文名稱。輸入並提交「大埔」或「Tai Po」後，地圖與清單會改以大埔區中心為基準，顯示 2 公里內的停車場；結果標題會顯示選定地區。

## 驗證結果

- 375×812 手機預覽確認：黑色圖例已移除、地圖下圓角完整可見、下方結果標題保留可視入口，地政總署標誌與版權仍在地圖上。
- 瀏覽器實測輸入 `Tai Po`：成功切換至「大埔區 · 2 公里」，載入 11 個符合目前篩選的停車場，最近一項距離 160 米。
- 瀏覽器實測「查看 11 個停車場」：頁面成功捲動至完整清單，`Pixels below viewport: 0`。
- 已通過 `pnpm test:domain`、`pnpm test:charging`、`pnpm test:photos`、`pnpm check` 和 `pnpm build`。
