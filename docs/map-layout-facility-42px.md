# 手機版附近設施地圖高度修正

日期：2026-10-12

## 變更

在 `max-width: 720px` 下，附近設施模式的 `.workspace` 父層和 `.map-column` 都比泊車模式各延伸 `42px`。原先只加高地圖欄而未加高父層，父層的 `overflow: hidden` 可能裁掉延伸部分，連帶遮住地圖底部搜尋、圖例等控制。

泊車模式高度保持原狀；只有 `.is-facility-mode`（不含專用路邊位模式）套用額外高度。`App.tsx` 維持不變，版面由 CSS 控制，沒有引入動態視窗高度計算。

## 維護檢查

`scripts/check-map-viewport-scope.mjs` 斷言設施模式父層與地圖欄都採用精確 `+ 42px` 規則，並保留泊車模式高度及排除動態高度計算的既有檢查。若修改篩選列高度，需同步調整父層、地圖欄與此斷言，並確認地圖底部控制仍完整可見。
