# 手機版附近設施地圖高度修正

日期：2026-10-13

在 `max-width: 720px` 下，泊車模式地圖欄沿用既有高度；附近設施模式地圖欄明確增加 `42px`，並同時設定相同的 `min-height`，避免手機瀏覽器或 Grid/Flex 壓縮高度。附近設施的 workspace 網格列設為 `auto`，讓父層按延伸後的地圖欄自然增高；底部搜尋與圖例控制仍留在地圖欄內。

變更僅作用於附近設施模式（不含路邊位專用模式），不更改定位素材、座標、字級或清單功能。`scripts/check-map-viewport-scope.mjs` 鎖定網格列及高度、最小高度精確增加 `42px` 的規則。
