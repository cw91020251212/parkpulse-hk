# 停車場水滴 marker 中央內容純白化

## 修正

停車場水滴 marker 的中央 `b` 內容元素明確設定 `color: #fff`。這確保空位數、狀態字與符號均為純白，不受外層繼承或底色影響。既有深色 `text-shadow` 僅保留在文字外圍，以改善淺色地圖底上的辨識度，不改變字面顏色、14px 最大安全字級、白框、漸層或水滴尺寸。

## 驗證

390px 手機地圖的計算樣式確認 marker 內容為 `rgb(255, 255, 255)`，並保留深色投影。`pnpm check`、一般建置、Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check` 全部通過。
