# 停車場 marker 漸層與數字陰影

## 修正

只調整停車場水滴 marker。中央白色空位數／狀態字加入深青色陰影，提高在地政總署淺色底圖上的可讀性。有位、滿位、關閉及無資料四種既有狀態色均改為同色系漸層。

水滴元素本身以 `rotate(-45deg)` 形成尖端；因此背景採用元素內「左深、右淺」的水平漸層，轉換後在畫面上正好呈現左下較深、右上較淺。白框、marker 尺寸、尖端座標、桃紅最近查看線及周邊設施／路邊位 marker 均未改動。

## 驗證

390px 手機地圖實測有 14 個停車場 marker；有位 marker 的計算背景為 `linear-gradient(to right, rgb(5, 118, 111), rgb(25, 203, 185))`，轉換矩陣為 -45°，中央文字陰影存在且可見。視覺檢查確認水滴在畫面上的左下深、右上淺效果與白字可讀性。`pnpm check`、一般建置、Pages 建置、Pages 資料檢查、PWA 檢查及 `git diff --check` 全部通過。
