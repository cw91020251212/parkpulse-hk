# 手機版公廁位置調整與地圖空間

位置未核實的場地級公廁可按住約 1.3 秒後，以同一手勢拖動；移動時地圖會暫停平移，標記座標即時預覽。放手後一次性寫入 `parkpulse:manual-toilet-positions:v1` 的 `localStorage`，避免每個觸控移動事件反覆寫入。官方精確座標不能拖動，本機修正亦不會標示成官方核實位置。

設定只留在該用家的瀏覽器，不會自動上傳或同步其他用家。要讓大家使用，需要匯出、人工核對後更新共享 JSON 並部署。地圖底部只保留原有「搜尋地區」與圖例兩個按鈕，不再增加「繼續調整／確定儲存」確認列。

兩行篩選膠囊高度為 32px，文字尺寸不變。手機端在標題與篩選列之間保留較寬鬆間距；地圖列填滿篩選後至手機畫面底部工具列的剩餘高度，底部按鈕貼齊視口底部。回歸檢查使用 `pnpm run test:manual-toilet-positions`，全專案型別檢查使用 `pnpm run check`。
