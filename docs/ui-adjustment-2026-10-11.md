# UI 高度修正（2026-10-11）

- 车种与设施筛选胶囊改为 26px 高；修正移动端覆盖规则原本把高度重新设为 40px 的问题。文字维持既有 14px，不缩小。
- 底部「搜尋地區」按钮与右侧地图图例下箭头统一使用 28px 高，并由同一 CSS 变量控制；两者在同一 flex 行垂直居中对齐。
- 控件尺寸调整不改变操作行为；另修正路边位必须配搭已选车种，未选车种时停止相应请求、隐藏路边位数据，并提示先选车种。

- 2026-10-11：點地政總署標誌會展開原生選單，可選「查看地圖資料／使用聲明」或「開啟地政總署 GeoInfo Map」；左側署名仍可直接查看聲明，選單不會推動地圖布局。
