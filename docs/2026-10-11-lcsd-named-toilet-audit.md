# 康文署戶外公園具名公廁全量核對（2026-10-11）

## 更正前次結論

使用者提供的地圖截圖清楚標示「大埔海濱公園五號廁所」。我前次只查閱康文署公園資料快照：該資料只提供公園／場地位置，沒有每間廁所的個別座標；我把「快照沒有廁所級點」錯誤推論成「沒有這間廁所」，亦沒有再查地政總署地名索引。這是查證不足，不能據此否定使用者的實地資訊。

兩個資料層各有用途：康文署資料證明場地設有廁所並提供園區位置；地政總署的官方具名地名點則能指出部分個別廁所的位置。底圖標籤本身不是可由程式讀取的資料列，但可以作為尋找官方地名索引的線索。

## 全量核對結果

- 逐一核對現有快照中的 **319 個康文署戶外公園／場地廁所紀錄**，以場地中英文名稱查詢地政總署位置搜尋服務。
- 僅接納名稱包含「廁所／洗手間／公廁」或相應英文詞、與康文署場地名稱及地區明確相符，而且可由香港格網座標轉為香港 WGS84 的官方具名點。
- 取得 **84 個非含糊具名候選點**；相同中英文官方名稱、座標均在 50 米內的重複結果合併後，保留 **80 個唯一具名點**。**1,481 個**模糊、鄰近或泛稱廁所結果不當作精確點；另有 249 個場地沒有可直接配對的具名結果，這不代表場內沒有廁所。
- 初次掃描有一個「晏架街遊樂場」回應傳輸不完整；其後直接重試地政總署官方搜尋，確認「晏架街遊樂場公廁／Anchor Street Playground Public Toilet」及其官方格網座標。此來源點與食環署已接入的同名點相距約 2.3 米，前端只顯示一個；相近但名稱不同的點不單憑距離刪除。
- 大埔海濱公園的地政總署索引找到 **二號、三號、四號、五號及六號廁所**。五號點座標為 **22.452717319, 114.187483421**；與官方地名「大埔海濱公園觀景臺」點相距約 **26 米**，與原先只有園區位置的康文署記錄相距約 **887 米**。因此，舊園區座標不能代替五號廁所點。
- 地名索引未找到一號或七號廁所的直接具名結果；本報告不因此宣稱它們不存在，也不以園區中心估算位置。

## 更新及呈現規則

具名點索引保存在 `data/lcsd-named-toilet-points.json`；可用 `pnpm audit:lcsd-named-toilets` 重新逐場查核，檢閱索引差異後以 `pnpm build:pages` 更新 GitHub Pages 快照。新場地名錄更新時，先重建康文署場地快照、再執行全量查核，審閱新增／移除點位後再建置一次。

康文署提供的園區座標仍標記為場地級／位置未核實並使用灰階圖示；地政總署有名稱明確的個別廁所點才使用精確廁所 marker。應保留資料來源與官方查詢連結；不得以底圖像素、園區中心或「附近」類 POI 猜出廁所座標。跨部門去重先以同一規則正規化名稱，再要求完整名稱完全相同且距離不多於 150 米；不採前綴或部分字串包含匹配，因此相近但名稱不同的廁所仍分開保留。

## 官方來源

1. 康文署設施資料目錄：場地、設施文字及園區座標。
2. 地政總署位置搜尋服務：官方具名公廁及香港格網座標。
3. 香港測繪處官方座標轉換服務：香港格網轉 WGS84。
4. 食環署公廁資料與漁護署郊野公園公廁快照：用於交叉核對重複點。
